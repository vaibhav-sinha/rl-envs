Figma now supports proportional resizing via the `Lock aspect ratio` option. This replaces the legacy `constrainProportions` option. `constrainProportions` maintains backwards compatibility by setting the new [`targetAspectRatio`](../../api/properties/nodes-targetaspectratio.md) field, but we encourage you to use the new property.

Previously, [createPage](../../api/properties/figma-createpage.md) could incorrectly create more pages than supported by Figma's Starter plan. This issue has been fixed.

**New**:

Figma now supports customizing underlines. The following changes were made to support getting and setting new underline features:

- [textDecorationStyle](../../api/TextNode.md#textdecorationstyle), [textDecorationOffset](../../api/TextNode.md#textdecorationoffset), [textDecorationThickness](../../api/TextNode.md#textdecorationthickness), [textDecorationColor](../../api/TextNode.md#textdecorationcolor), and [textDecorationSkipInk](../../api/TextNode.md#textdecorationskipink) are now supported on [TextNode](../../api/TextNode.md)
- Added support for [textDecorationStyle](../../api/TextNode.md#textdecorationstyle), [textDecorationOffset](../../api/TextNode.md#textdecorationoffset), [textDecorationThickness](../../api/TextNode.md#textdecorationthickness), [textDecorationColor](../../api/TextNode.md#textdecorationcolor), and [textDecorationSkipInk](../../api/TextNode.md#textdecorationskipink) in [getStyledTextSegments()](../../api/properties/TextNode-getstyledtextsegments.md)
- Added ranged getters [getRangeTextDecorationStyle()](../../api/node-properties.md#getrangetextdecorationstyle), [getRangeTextDecorationOffset()](../../api/node-properties.md#getrangetextdecorationoffset), [getRangeTextDecorationThickness()](../../api/node-properties.md#getrangetextdecorationthickness), [getRangeTextDecorationColor()](../../api/node-properties.md#getrangetextdecorationcolor), and [getRangeTextDecorationSkipInk()](../../api/node-properties.md#getrangetextdecorationskipink).
- Added ranged setters [setRangeTextDecorationStyle()](../../api/node-properties.md#setrangetextdecorationstyle), [setRangeTextDecorationOffset()](../../api/node-properties.md#setrangetextdecorationoffset), [setRangeTextDecorationThickness()](../../api/node-properties.md#setrangetextdecorationthickness), [setRangeTextDecorationColor()](../../api/node-properties.md#setrangetextdecorationcolor), and [setRangeTextDecorationSkipInk()](../../api/node-properties.md#setrangetextdecorationskipink).

**New**:

Figma now supports per-paragraph fields. The following changes were made to support getting and setting indent and spacing per paragraph:

- Added support for [paragraphSpacing](../../api/node-properties.md#paragraphspacing), [paragraphIndent](../../api/node-properties.md#paragraphindent), and [listSpacing](../../api/node-properties.md#listspacing) in [getStyledTextSegments()](../../api/properties/TextNode-getstyledtextsegments.md)
- Added ranged getters [getRangeParagraphSpacing()](../../api/node-properties.md#getrangeparagraphspacing), [getRangeParagraphIndent()](../../api/node-properties.md#getrangeparagraphindent), and [getRangeListSpacing()](../../api/node-properties.md#getrangelistspacing).
- Added ranged setters [setRangeParagraphSpacing()](../../api/node-properties.md#setrangeparagraphspacing), [setRangeParagraphIndent()](../../api/node-properties.md#setrangeparagraphindent), and [setRangeListSpacing()](../../api/node-properties.md#setrangelistspacing).
- [paragraphSpacing](../../api/node-properties.md#paragraphspacing) and [paragraphIndent](../../api/node-properties.md#paragraphindent) are now supported on [boundVariables](../../api/node-properties.md#boundvariables)

**New**:

We’ve made updates to our Plugin and REST APIs so you can build more powerful plugins that increase efficiency and create more dynamic user experiences.

- **Annotations and measurements**: Create and edit annotations and measurements from Dev Mode through the Plugin API. Generate bulk annotations, format annotations according to a style or template, add context or links from other tools to annotations, and more. Learn more about [annotations](../../api/Annotation.md) and [measurements](../../api/Measurement.md).
- **Rich text formatting for component description**: Build plugins that can read and edit the full rich-text version of the component description, giving users the same level of detail as Figma's UI. [Learn more](../../working-with-rich-text.md)
- **Advanced prototyping interactions**: Access all prototyping reactions through the Plugin and REST APIs to bring Figma prototypes to life in other interaction tools. [Learn more](../../api/Reaction.md)

**New**:

The Plugin API now contains support for page dividers:

- Create a page divider node appended to the document node's list of children using [createPageDivider](../../api/properties/figma-createpagedivider.md).
- Change the [name](../../api/properties/nodes-name.md) of an empty [PageNode](../../api/PageNode.md) to a page divider name to turn the node into a page divider.
- Read a page node's [isPageDivider](../../api/PageNode.md#ispagedivider/) property to determine whether the node is a page divider.

This version of the plugin-typings package was skipped.

New

- Component properties ([componentPropertyDefinitions](../../api/ComponentPropertyDefinitions.md), [componentProperties](../../api/ComponentProperties.md)) can now have bound variables for their value!

In February 2024, Figma [implemented dynamic page loading](/docs/plugins/updates/2024/02/21/version-1-update-87/#apis-for-dynamic-page-loading) for Figma design files. Now, dynamic page loading has been extended to FigJam files. If your plugin handles FigJam files, you should follow the steps in [Migrating Plugins to Dynamically Load Pages](../../migrating-to-dynamic-loading.md).
