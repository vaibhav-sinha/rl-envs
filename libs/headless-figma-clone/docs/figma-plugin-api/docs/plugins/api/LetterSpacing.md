- LetterSpacing

```
type LetterSpacing = {  
  readonly value: number  
  readonly unit: "PIXELS" | "PERCENT"  
}
```

An object representing a number with a unit. This is similar to how you can set either `100%` or `100px` in a lot of CSS properties.
