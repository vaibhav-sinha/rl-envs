- maxLines

On this page

The maximum number of lines a text node can reach before it truncates. Only applicable when [`textTruncation`](TextNode-texttruncation.md) is set to `"ENDING"`.

Supported on:

- [TextNode](../TextNode.md)

## Signature[​](#signature "Direct link to Signature")

### [maxLines](TextNode-maxlines.md): number | null

## Remarks[​](#remarks "Direct link to Remarks")

The value must be >= 1. To disable truncation at a maximum number of lines, set to `null`.
